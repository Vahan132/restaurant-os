# Отчёты и дашборд

Каждый заказ, платёж и стол попадают в ваш дашборд по ходу обслуживания — так что вы можете читать
вечер, пока он ещё перед вами, а не на следующее утро.

## Живой дашборд

Дашборд сводит ключевые цифры с одного взгляда:

- **Продажи** — выручка на текущий момент, по часам и по категориям
- **Гости** — сколько гостей вы обслужили
- **Средний чек** — траты на гостя и на стол
- **Хиты продаж** — что продаётся, а что нет

<Callout tone="tip" title="Создан для вашего телефона">
  Дашборд спроектирован так, чтобы его было удобно читать на телефоне между сменами, а не только на большом экране в
  офисе.
</Callout>

## Отчёты

Углубитесь с отчётами, которые можно фильтровать по диапазону дат, секции, официанту или категории:

| Отчёт | Отвечает на вопрос |
| --- | --- |
| Сводка по продажам | Сколько мы заработали и когда? |
| Эффективность меню | Какие позиции оправдывают своё место в меню? |
| Труд против продаж | Достаточно ли у нас персонала под спрос? |
| Платежи | Как платят гости? |

## Экспорт и API

Экспортируйте любой отчёт в CSV для вашего бухгалтера или ваших собственных таблиц. На тарифе **Pro**
[API и вебхуки](#доступ-к-api) дают вам живой доступ к тем же данным.

### Доступ к API

Тарифы Pro могут читать данные по продажам, меню и заказам программно и подписываться на вебхуки для событий
вроде *заказ завершён* или *стол закрыт* — полезно для бухгалтерии, программ лояльности или BI-инструментов.

```bash
curl https://your-place.restaurantos.app/api/v1/reports/sales \
  -H "Authorization: Bearer $RESTAURANT_OS_TOKEN"
```

<Note>
  Отчёты в реальном времени включены в тарифы Growth и Pro. Starter включает дневную сводку по продажам. Продвинутая
  аналитика, экспорт и API — это функции Pro, см. [Цены](/pricing).
</Note>

## Несколько точек

Операторы с несколькими заведениями получают консолидированную отчётность, которая сводит всё воедино, при этом по-прежнему позволяя
вам углубиться в отдельную точку.
