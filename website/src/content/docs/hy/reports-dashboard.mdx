# Հաշվետվություններ և վահանակ

Յուրաքանչյուր պատվեր, վճարում և սեղան հոսում է ձեր վահանակ սպասարկման ընթացքում — այնպես որ կարող եք կարդալ
երեկոն, քանի դեռ այն ձեր առջևում է, ոչ թե հաջորդ առավոտյան։

## Կենդանի վահանակը

Վահանակը ամփոփում է հիմնական թվերը մեկ հայացքով:

- **Վաճառքներ** — մինչ այժմ եկամուտ, ըստ ժամի և ըստ կատեգորիայի
- **Հաճախորդների թիվ** — քանի հյուր եք սպասարկել
- **Միջին հաշիվ** — ծախսը մեկ հաճախորդի և մեկ սեղանի համար
- **Լավագույն վաճառվողներ** — ինչն է շարժվում և ինչը՝ ոչ

<Callout tone="tip" title="Կառուցված ձեր հեռախոսի համար">
  Վահանակը նախագծված է հերթափոխերի միջև հեռախոսի վրա ընթեռնելի լինելու համար, ոչ միայն գրասենյակի մեծ
  էկրանին։
</Callout>

## Հաշվետվություններ

Խորացեք հաշվետվություններով, որոնք կարող եք զտել ըստ ամսաթվերի միջակայքի, բաժնի, մատուցողի կամ կատեգորիայի:

| Հաշվետվություն | Պատասխանում է |
| --- | --- |
| Վաճառքների ամփոփում | Որքա՞ն ենք վաստակել և ե՞րբ։ |
| Մենյուի արդյունավետություն | Որ կետերն են արդարացնում իրենց տեղը մենյուում։ |
| Աշխատուժ ընդդեմ վաճառքների | Արդյոք բավարա՞ր անձնակազմ ունենք պահանջի համար։ |
| Վճարումներ | Ինչպե՞ս են վճարում հյուրերը։ |

## Արտահանումներ և API-ն

Արտահանեք ցանկացած հաշվետվություն որպես CSV ձեր հաշվապահի կամ ձեր սեփական աղյուսակների համար։ **Pro** պլանում
[API և webhook-ները](#api-մատչելիություն) ձեզ տալիս են կենդանի մատչելիություն նույն տվյալներին։

### API մատչելիություն

Pro պլանները կարող են ծրագրային եղանակով կարդալ վաճառքների, մենյուի և պատվերների տվյալները և բաժանորդագրվել webhook-ների այնպիսի իրադարձությունների համար,
ինչպիսիք են *order completed* կամ *table closed* — օգտակար հաշվապահության, լոյալության կամ BI գործիքների համար։

```bash
curl https://your-place.restaurantos.app/api/v1/reports/sales \
  -H "Authorization: Bearer $RESTAURANT_OS_TOKEN"
```

<Note>
  Իրական ժամանակի հաշվետվությունները ներառված են Growth և Pro-ում։ Starter-ը ներառում է օրական վաճառքների ամփոփում։ Առաջադեմ
  վերլուծությունները, արտահանումները և API-ն Pro գործառույթներ են — տե՛ս [Գնագոյացում](/pricing)։
</Note>

## Բազմաֆիլիալ

Մի քանի ռեստորան ունեցող օպերատորները ստանում են համախմբված հաշվետվություն, որը ամփոփում է ամեն ինչ, միաժամանակ թույլ տալով
ձեզ խորանալ առանձին վայրի մեջ։

## Հաջորդը՝ կառավարեք ձեր հաշիվը

Կառավարեք ձեր պլանը, հաշիվ-ապրանքագրերը և թիմը [Հաշիվ և վճարում](/docs/account-billing)-ում։
