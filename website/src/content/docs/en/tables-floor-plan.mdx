# Tables & floor plan

A floor plan turns Restaurant OS into a live map of your room. Servers seat faster, managers see the
whole picture, and the kitchen knows where every order is going.

## Design your room

Use the drag-and-drop editor to recreate your space. Add tables, set how many each seats, and group
them into sections like *Patio*, *Bar*, or *Main*.

<Steps>
  <Step title="Add tables">
    Drop tables onto the canvas and label them. Set a seat count for each.
  </Step>
  <Step title="Create sections">
    Group tables into sections so you can assign servers and filter views.
  </Step>
  <Step title="Save your layout">
    Layouts are versioned, so you can keep a separate plan for brunch, dinner, or a private event.
  </Step>
</Steps>

## Reading table status

Each table carries a color so you can read the room at a glance:

| Status | Meaning |
| --- | --- |
| Open | Available to seat |
| Seated | Guests are at the table |
| Ordered | An order is in progress |
| Check dropped | Awaiting payment |

<Callout tone="tip" title="Watch your turn times">
  Restaurant OS tracks how long each table has been in each state, so you can spot tables that are
  ready to turn — and ones that need attention.
</Callout>

## Transfers and merges

Move a check between tables when guests relocate, or merge two tables for a larger party. The order,
items, and history follow along automatically.
